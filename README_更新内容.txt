TRPG Archive v4 更新ファイル

既存のGitHubリポジトリにあるファイルを差し替えるためのZIPです。
ZIP内の3ファイルを、GitHubリポジトリ直下の同名ファイルに上書きしてください。

差し替えるファイル：
- app.js
- index.html
- styles.css

重要：config.js は含めていません。Supabaseの接続情報が入っているため、現在のconfig.jsはそのまま残してください。
supabase/schema.sql も変更不要です。SQL Editorで再実行する必要はありません。

今回の変更：
1. CSVは「シナリオ名」「タイトル」などのタイトル列だけ必須です。
2. 人数・R指定・有償・サークル名・URLなどの列がシートにない場合も取り込めます。
3. CSVに存在しない列や空欄は、既存データを上書きしません。
4. 人数は「ソロ／タイマン／2PL／3PL／4PL／5PL／6PL／人数融通有」の複数選択式です。
5. 人数セルに「2PL、3PL」のように複数値を書いた形式と、人数ごとに列が分かれたチェックボックス形式に対応します。
6. 作者名ではなくサークル名として画面表示・検索します。CSV見出しは「サークル名」「サークル」「頒布元」「発行元」などに対応します。旧CSV互換のため「作者」列もサークル名として取り込みます。
7. 左側の人数フィルターも8種類に対応します。

適用後：
- GitHubで3ファイルを上書きしてCommit changes。
- GitHub Pagesの更新後、PCで Ctrl + F5 で再読み込み。
- ログインし直したり、SupabaseのSQLを再実行したりする必要はありません。

CSV取り込みはスプレッドシートの各タブをCSVで書き出し、1ファイルずつ読み込んでください。

備考：既存データとの互換性を保つため、Supabase内部の既存列名 author_name は変更していません。画面とCSV上の呼び名は「サークル名」です。
